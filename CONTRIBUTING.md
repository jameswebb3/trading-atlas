# Suggest a project or correct a review

The Atlas improves when a suggestion answers a concrete engineering question. Open an issue or pull request with the project URL, the relevant mechanism, and the specific public documentation or code path worth inspecting. Popularity alone is not an inclusion reason.

For a correction, identify the affected review and claim, provide the upstream file and commit or release that changes it, and explain the practical consequence. We will update the review date, source links, and [change log](CHANGELOG.md) when a conclusion changes.

Please do not submit private trading data, credentials, unpublished strategies, or copied source files. An upstream README statement is a lead; a source observation or inspected test supports a stronger claim. Reported returns need their evaluation conditions stated and are not treated as independently replicated by this catalog.
